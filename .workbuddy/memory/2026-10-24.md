# 2026-10-24

## dsh-long-input 插件 v0.2.0（已安装并生效）
- 需求：DSH Web 输入框太小，做「长内容输入」弹窗插件：左 textarea 写 Markdown / 右 marked 实时渲染 / 中线可拖分栏，确定时覆盖写回输入框。
- 技术选型：纯 textarea、marked v12.0.2 vendored、覆盖写回、无构建步骤。
- 最终实现：改为标准 DSH bundle（`@local/dsh-long-input`），不再是独立 DOM 注入脚本。
  - 按钮 slot：`conversation.input.left`，order 0（输入框底部工具栏，权限/计划控件右侧）。
  - 弹窗 slot：`shell.overlay`，order 900；两 slot 用模块级 external store 共享开关。
  - 写回：普通文本用 `inputActions.setDraft(text)`；有指令/引用时用结构化 `{ text, references, command }`，保留 chip，不依赖 Lexical / DOM 选择器。
  - 快捷键：Enter 换行、Ctrl/Cmd+Enter 写回、Esc 关闭（打开关闭确认）；比例存 localStorage（20–80）。
  - 打开弹窗时读取 `InputState`：指令 token 与 `@` 引用 chip 不进入编辑区，写回时按原顺序作为固定前缀重新附加。
  - 关闭确认：X / 取消 / Esc 弹出两个选择（退出不写回 / 退出并写回），底部「记住我的选择」；偏好存 `dsh-long-input:closeChoice`。
  - 插件信息页：注册 `plugins.bundle.config`（key `@local/dsh-long-input`），提供两个可切换选项（都不选=每次询问）、即时生效、恢复默认设置（清关闭行为 + 分栏比例 50%）。
  - Esc/Ctrl+Enter/Tab 改为 window 捕获阶段监听，点击蒙版后仍有效。
  - 编辑区和预览区统一使用原生输入框字体变量（`--dsw-font-family`、`--dsh-content-font-size`、`--dsh-content-font-delta`）。
  - 弹窗 footer token 估算代码已保留，但由 `SHOW_TOKEN_COUNT = false` 关闭，当前不显示；公式 `Math.ceil(text.length / 4)`，只统计 Markdown 原文。
  - 主题：仅 `--dsw-alias-*` token；中英文 locale；原创 icon；marked MIT 声明。
  - 按钮文字跟随 locale：中文「长内容输入」/ 英文「Long Input」。
- 安装：`plugin_manager install_bundle D:\work\projects\dsh\dsh_md_input_window`，application=applied。
- 验证：client graph 包含插件；Slots 中 `conversation.input.left` / `shell.overlay` / `plugins.bundle.config` 均已出现 `long-input` 注册；无模块加载失败。
- 行为探针实测通过：按钮/弹窗存在、原生草稿带入、Markdown 预览、蒙版点击后 Esc 仍弹出关闭确认、退出不写回、退出并写回、记住选择后跳过确认、再次打开仍带入草稿。测试后已恢复原草稿并清除测试偏好。
- 结构化草稿探针实测通过：原生 `/goal @README.md` 打开后编辑区只显示普通文本；写回后草稿为 `/goal @README.md UPDATED CONTENT`，引用数量仍为 1；关闭无报错。测试后已恢复原草稿。
- Token 计数实现和探针数据保留在历史中；当前通过 `SHOW_TOKEN_COUNT = false` 隐藏。隐藏探针实测：弹窗打开正常、`.dli-token-count` 不存在、footer 正常。测试后已关闭弹窗。
- 已知边界：指令/引用会被移到编辑内容之前（作为固定前缀）；marked 原始 HTML 未消毒；切换 Session 自动关闭弹窗；记住选择后可在插件信息页改回或恢复默认。
